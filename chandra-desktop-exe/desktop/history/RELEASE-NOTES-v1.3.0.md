# Chandra Desktop v1.3.0: Starlight

- **Starlight, the new look.** Deep space led by blue, a touch of periwinkle, and star colour for the one light source. A **Gradient ASCII** sky (ported from React Bits, shaders unchanged) lights the top of the window above the dark arc of the horizon; the pointer scrambles its glyphs and a click sends a wave. The older drawn arcs are gone in Starlight. An ASCII **eclipse corona** rings the moon mark. Both quicken while Chandra thinks and works and warm while it speaks. Composer, buttons, chips, panels, the speaking light and the cursor all follow. Settings > Interface > Look switches back to **Classic** black at any time. Without a GPU (Windows' software renderer) the sky draws at quarter resolution and 10 fps, Lite mode and Reduce motion keep it still.
- **Placeholder art in Chandra's colours.** Wherever an image is missing, **Grainient** (React Bits) paints one from Chandra's own combos, seeded so the same thing always gets the same art, and it moves under the mouse (stir by moving, twirl by clicking): the avatar, artifact card covers, broken images, images in apps Chandra makes (`<img data-placeholder>`, or any image the sandbox can't load) and files without a preview.
- **The target cursor, in app previews.** In the apps Chandra makes (their sandboxed previews), the React Bits Target Cursor replaces the pointer: a spinning reticle and dot that lock onto each element and name it with its source line. Everywhere else Chandra keeps its own supplied Mac cursors. **Click to use. Shift + right-click to see the source:** in an app preview, the artifact's Source tab at that line; on an artifact chip or card, its source; on any other part of Chandra, the exact `file:line:column` places in Chandra's own source where it is made, styled and driven (`/source/find`, a plain text search of Chandra's source files only, said as such). Shift + click still shows where an artifact came from.
- **No key to paste.** The Claude key field is gone from Settings. Chandra uses the key in `chandra.env` (Chandra Setup can put it there) or this computer's `ANTHROPIC_API_KEY`, and Settings says which; with neither, it thinks with the Chandra Engine.
- **Preview before you save.** Every download (artifact Download, files Chandra makes, exports, your `.ananta` file) opens a preview of the exact bytes first: images, SVG (scripts never run), PDF, audio, video, code, Markdown, tables, JSON, HTML in the sandbox, and a size + SHA-256 + hex card for anything else. Save is inside the preview. Attachments in the composer preview with a click too.
- **A setup that looks like Chandra.** Chandra Setup is now Chandra's own program: frameless, Starlight, SF Pro, traffic lights, the ASCII sky. Run it again and it offers **Update / Repair** or **Uninstall** (your data kept unless you tick otherwise). About 13 MB.

Unchanged: the brain, approvals before risky actions, the pairing code and loopback binding, artifacts and their versions, voice, memory, `.ananta` files, MCP tools and the keyboard shortcuts.
