# Chandra Desktop v1.2.0: the Artifacts release

- **Artifacts.** What Chandra makes is now kept: code, HTML apps and prototypes, Markdown documents, SVG graphics, charts, CSV tables and JSON data. The model has a `create_artifact` tool for making and revising them. A file Chandra writes on your computer is kept as one too, and so is a long code block in a reply, which moves out of the reply so the reply stays short. Each artifact has versions (Revise, Regenerate and Restore always add one; nothing is silently replaced). They live in Chandra's data folder (`artifacts/`), survive restarts and reinstalls, and have their own page (key **7**). They also appear as chips under the reply that made them.
- **Click opens, Shift+click inspects.** Clicking an artifact does its normal thing: an app runs, a document opens to read, code opens in the source view, a table or chart draws. Shift+click (or Shift+Enter, or the **Inspect source** tab) shows where it came from instead. You see the conversation and message, the file on this computer it was read from, written to or attached as, with the exact lines when its content can be found there, and the Chandra code that handles it, with line ranges read from the source files at that moment. A path the model only mentioned is shown and never opened. Chandra never searches your computer, and files that usually hold secrets are never shown. **View lines** shows the code in Chandra; **Open in editor** uses VS Code at the right line when it's installed, otherwise a plain text editor (never an app that could run the file).
- **Safe previews.** HTML artifacts run in a sandboxed frame that cannot reach Chandra, its key, your files or the network; scripts may load only from three public CDNs. SVG draws as an image, so its scripts never run. Markdown, code, tables and charts are built from text, never from raw HTML. Runtime errors and blocked requests from an app show under the preview.
- **The speaking light.** A Strands orb (ported from React Bits, shaders unchanged) rises over the composer's top-right edge. It is calm at rest, quickens while Chandra thinks and works, opens while a reply lands, and follows the voice while Chandra speaks. Chandra's voice is the browser's speech engine, which gives no audio samples, so the orb follows the real playback events: start, every word, end. An interruption drops it to zero at once. While listening it follows the microphone level, but only when microphone permission was already granted; it never asks for permission itself. Without WebGL2, or in Lite mode, a still CSS orb stands in. It pauses when off screen, keeps to 24 fps at rest, and respects Reduce motion.
- **The composer owl.** The supplied “Owl Opens Laptop” animation perches on the composer's left edge, played from its own frames and timing. It blinks at rest, opens its laptop when you send a request, works while Chandra thinks, and closes it when the answer arrives.
- **One state, said in words.** A new state bus follows what Chandra is really doing (thinking, working, responding, speaking, listening, interrupted, error, needs you). It drives the orb, the owl, and a small line in the composer that says the state in words.
- **Attach really attaches.** The + button and drag-and-drop add up to 4 files to the next message (text up to 512 KB, images up to 8 MB; images go to Claude, and the local engine is told it can't see them). In Chandra's own window the native picker keeps each file's path, so an artifact made from it can point back to it.
- **Send becomes Stop** while Chandra thinks or works (the same stop as the card's Stop), and **Stop speaking** while Chandra talks. Enter to send and Shift+Enter for a new line are unchanged.
- **Precision cursor.** Corner brackets (ported from React Bits' Target Cursor) lock onto artifacts and their actions with a short label. Holding Shift over an artifact relabels it “Inspect source”. Your own pointer always stays. It is off on touch screens and in Lite mode, and can be switched off in Settings > Interface.
- **Credits** are in Settings, and the full notices are in `THIRD-PARTY-NOTICES.md`.
- **Editable source again.** `app.v1.html` plus `ui/*.js|css` are the UI's source; `python pack.py` builds them into `chandra.py`, and `python pack.py --check` verifies the embedded copy is current. `tests/` holds host tests (standard library only).

Fixed along the way: older chat turns kept their text when an image was dropped from history (previously the whole turn became “(older screenshot removed)”). Voice requests are kept as chats, so their artifacts can link back.

Unchanged: the black-only look, the brain (Claude through `chandra.env`, otherwise the Chandra Engine), approvals before risky actions, the pairing code and loopback binding, the corner failsafe, Stop all, memory and `.ananta` files, timers, voice, Screen sense, MCP tools and the existing keyboard shortcuts (1–6 as before; 7 is new).

**One setup file.** `Chandra-Setup-v1.2.0.exe` (about 13 MB, per-user, no administrator rights, 64-bit Windows) carries everything, Chandra's own Python included. It is built by `installer/build_installer.py`. It adds a Start-menu "Chandra in your browser" for computers without WebView2, refuses to install over a running Chandra, and uninstalls only what it installed.
