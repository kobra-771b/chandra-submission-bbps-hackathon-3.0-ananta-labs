# Chandra 1.1.0: Diagnostics

- **Diagnostics replaces Activity** at the top of the rail. A health score, then the system (version, Windows, processor, Python, uptime, WebView2, ports, data folder), the brain and keys (set or not, never their values), voice models, safety, this window (mode, style and colour, smoothness in fps, graphics, memory, network, maths support, location), live connection times to Claude and Gemini (free list calls, no tokens), every self-check, the recent errors and the start log. **Run full check** times the connections; **Copy report** puts everything in one block to paste, with keys and tokens removed. The activity list is still underneath.
- **Look previews in onboarding.** Modern and Legacy each show their own logo, tinted by the colour you pick; the descriptions are gone.
- **Installer names** now read `Chandra v1.1.0-official.exe` and `Chandra v1.1.0-official-personal.exe`.
