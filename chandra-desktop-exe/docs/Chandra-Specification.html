Overview

What it is

Chandra is one assistant with a home screen, memory, playbooks and artifacts. You talk to it, it answers in a natural voice, and when you ask it to do something on your computer it shows what it is about to do and waits for your tap. It thinks with Claude when it has a key, with Gemini otherwise, and with a local engine when it has neither or the internet is gone. Its window is a calm column on an aurora sky, with the Nebula orb at the centre.

Features

What it does

Voice first

Tap the moon, hold it or hold Space to talk; Ctrl+Space toggles. Chandra listens again after it answers and you can talk over it to interrupt. Captions show what you said and what Chandra says, the spoken sentence lit up.

Nebula, the voice orb

A soft cloud sphere inside a turning shell of light points. Each latitude of the shell follows one band of the sound, bass at the equator and highs toward the poles. WebGL 1, the child of the React Bits Sky Cloud and Pulsar designs.

Listening (the Ear)

The page records 16 kHz audio, finds where speech starts and ends (voice activity detection, with push-to-talk), and the host has Gemini transcribe English, Hindi and Hinglish, even mixed in one sentence. Without a key it falls back to the browser's recogniser.

A natural voice

Gemini neural speech (Sulafat by default) with a gentle Indian-English accent or natural Hindi, sentence by sentence. Anything written for the eye (markdown, links, code, emoji, formulas) is never read aloud. Falls back to the best neural voice on the computer.

Hindi and Hinglish

EN / हि / Mix switch on Home, Hindi voices chosen by script, Hindi stop-words ("बस", "धन्यवाद"), and answers in the language you used.

The aurora sky

A WebGL shader of soft colour fields and slow curtains in Chandra's blues, the planet's rim below, fine stars and grain. It quickens while Chandra thinks, cools while it listens and warms while it speaks.

Computer control, built in

Screen, mouse, keyboard and Screen sense go through the window's own native channel (pywebview js_api): no bridge, no pairing code, no screen frames over HTTP. While the window is open the HTTP /act route answers 403.

Two taps for a task

Allow a task once to start it, accept the result before it finishes. Deleting, moving or writing files, power, clipboard writes, shell commands, extra tool servers and anything that sends or pays ask every time.

Small, always-on safeguards

No wiping commands (rm -rf /, format, shadow-copy deletion), no typing card numbers (Luhn checked), API keys, tokens or private keys, a brake at 45 clicks a minute, and no screen sensing while a password manager, bank or private window is in front.

The brain

Claude when it has a key, then Gemini (free tier, with screen vision), then the local Chandra Engine. CHANDRA_BRAIN forces one. Claude Sonnet 5.5; Gemini 3.5 Flash with 3.6 Flash and 3.1 Flash-Lite as fallbacks.

Recall by meaning

Memory is searched by embedding (Gemini gemini-embedding-001, 768 dimensions), not just keywords. About 0.6 s a lookup.

Everyday skills

Weather, Wikipedia, dictionary, currency and units, no key needed.

Artifacts

Anything substantial (code, HTML apps, documents, SVG, charts, tables, JSON) becomes a versioned, persistent artifact on its own page. HTML artifacts run in a sandboxed iframe with no network and no access to Chandra, its keys or your files.

Playbooks, memory and MCP

Reusable Playbooks replace automations; memory travels as .ananta files; extra MCP tool servers can be added and always ask first; diagnostics keep a redacted error log.

Markdown and LaTeX

Replies are drawn as Markdown with LaTeX maths ($x^2$, $$…$$) through KaTeX as MathML, using the computer's own math font.

Always opens

A second launch shows the existing window; Update takes over a running copy; if WebView2 or .NET is missing Chandra opens in your browser with a clear message; a start log records every launch.

Architecture

How the pieces fit

Windowpywebview + WebView2
the page, Nebula, aurora
↔
JsApinative channel
act, screen_look, stt, tts
↔
Hostchandra.py
safeguards, approvals, tools
→
BrainsClaude · Gemini · engine

The page holds no API key; it asks the host. Inside the native window computer control, screenshots, listening and speech go through JsApi, not HTTP, and the loopback /act route refuses with 403. In browser mode (--browser) the loopback bridge with a pairing code is used instead. A single-instance handshake on port 48651 hands a second launch to the running window.

Safety and privacy

Quiet, always on

Keys

An API key lives in exactly one place: chandra.env in %APPDATA%\Chandra. The page never holds it, file tools cannot read that folder, and keys are redacted from logs (Claude and both Gemini key formats).

Approvals

Allow a task once, accept the result before it finishes. Risky actions ask every time. Chandra's own screenshots refuse a password manager.

Safeguards

Wiping commands, typed secrets and runaway clicking are stopped with a plain reason. Anything stopped is noted in the error log.

Sandboxed artifacts

HTML artifacts run in an iframe with a strict content policy: no network, no access to Chandra, its keys or your files.

Install

One installer, no administrator

Chandra-Setup-v1.0.0.exe installs per user, includes Chandra's own Python, and adds Chandra to the Desktop (optional) and Start menu (Chandra, Chandra in your browser, Set up Chandra, Uninstall). Run it again for Update / Repair or Uninstall; your data folder is kept unless you tick “Also remove my data”. Flags: /S silent, /uninstall, /D=<folder>. Exit codes: 0 done, 1 cancelled, 2 failed. Log: %TEMP%\Chandra-Setup.log.

A personal setup can carry your keys; Chandra moves them into its data folder on first launch. Anyone holding such a file can read the keys, so it is for your own computers only.

Build and test

For developers

python desktop/source/pack.py builds the page and embeds it in chandra.py. python -m unittest discover -s desktop/source/tests runs the 40 unit tests. python installer/chsetup.py build STUB.exe . VERSION OUT.exe [KEYS.env] rebuilds the installer around the toolbox, keeping the setup program and its interface.
